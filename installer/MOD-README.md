# Havendock FPS Fix 2.0.0

More FPS for big late-game colonies. The mod skips work the game repeats every frame even though nothing on screen changes. Your colony, your saves and how the game plays stay the same.

## Using it

- **M**: turn the mod off and on to see the difference (a message shows ON or OFF).
- **Pause/Break**: open the mod menu. Under Havendock FPS Fix you can turn on an FPS counter, change the M key, and switch each fix off or on under Settings.

## Removing it

Delete this folder (`Havendock\Mods\{MODID}`). The game goes back to normal.

## Something looks odd?

Press **M**. If it goes away, it's the mod: switch off the matching setting in the mod menu and please report it at {REPORT}.
